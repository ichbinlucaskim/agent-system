# Links only

Useful reading that is not stored in this library. Links, one line each, no
downloads and no summaries.

These are linked rather than mirrored because redistributing them is not ours
to do. They are published work sitting at a stable URL under someone else's
control, and the right way to point at them is a link that resolves to the
current version rather than a copy that silently goes stale in a folder here.
The arXiv PDFs in `topics/*/pdf/` are a different case: arXiv publishes under
terms that permit that kind of local copy, and each one is recorded in
`MANIFEST.md` with a checksum so the copy can be checked against the source.

- Anthropic, Building Effective Agents
  https://www.anthropic.com/engineering/building-effective-agents
  The workflow and agent patterns the sibling lab repository is organised around.

- Anthropic, Effective context engineering for AI agents
  https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents
  Treating the context window as a budget rather than as a container.

- Lilian Weng, LLM Powered Autonomous Agents
  https://lilianweng.github.io/posts/2023-06-23-agent/
  A survey-style overview that connects several of the papers in this library.
