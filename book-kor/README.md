# Agent Systems (한국어판)

대규모 언어 모델을 기반으로 하는 에이전트 시스템의 설계, 구축, 평가, 운영을 다루는 개론서다.

이 분야의 자료는 대체로 두 극단에 몰려 있다. 한쪽에는 특정 프레임워크의 사용법이 있고,
프레임워크가 바뀌면 함께 낡는다. 다른 쪽에는 개별 기법을 제안하는 연구 논문이 있고,
시스템 전체를 어떻게 조립할지는 알려 주지 않는다. 이 책은 그 사이를 채우려 한다.
왜 이 부품이 필요한지, 언제 그것을 쓰지 말아야 하는지, 고를 때 무엇을 치르는지를 적는다.

## 무엇이 들어 있는가

일곱 부, 스물세 장이다.

1. **에이전트란 무엇인가**: 구조 전체와 루프의 형태. 무엇이 에이전트이고, 다음 스텝을 누가 정하는가
2. **컨텍스트를 다루는 기술**: 예산의 단위와 조립의 안쪽. 유한한 컨텍스트에 무엇을 언제 실을 것인가
3. **도구와 외부 세계**: 환경으로 나가는 통로. 도구와 그 반환, 능력이 공급되는 경로, 출력의 형식
4. **지식과 기억**: 밖에 둔 것을 찾아 들이는 장치와 세션을 넘는 기억
5. **루프를 돌리는 일**: 순환을 바깥에서 소유하는 제어. 언제 멈추고 무엇을 남기고 어떻게 다시 시작하는가
6. **평가와 관측**: 좋아졌다는 것을 무엇으로 아는가, 실행에서 무엇을 남겨야 나중에 볼 수 있는가
7. **운영, 안전, 거버넌스**: 되돌릴 수 없는 결과 앞에 누구를 세우고, 밖에서 오는 텍스트를 어떻게 받는가

## 누구를 위한 책인가

언어 모델 API를 한 번이라도 직접 불러 본 사람, 그리고 에이전트 시스템을 큰 틀에서
이해하려는 사람을 염두에 두었다.
