# agent-system

Writing and code on agent systems built on large language models. A book in two
editions, a lab course, a paper library, design cases, and worked examples.

## What Is Here

| Directory | What it is |
| --- | --- |
| [`book-kor/`](book-kor/) | Agent Systems, the book. Korean edition, 23 chapters, 252 pages |
| [`book-eng/`](book-eng/) | The same book in English, 302 pages |
| [`agent-lab/`](agent-lab/) | A lab course. Nineteen labs in four tracks, Python, no framework |
| [`paper/`](paper/) | A reading library. Sixteen arXiv papers in seven topics |
| [`system-design/`](system-design/) | Design cases. One folder per system shape |
| [`projects/`](projects/) | Worked examples. Runnable code for some of the cases |

## How the Parts Relate

The book is the part you read. It says why a component is needed, when not to
use it, and what you pay when you pick it. `agent-lab` is the part you write:
the same mechanisms, built by hand and checked with tests. `paper` holds the
sources the book cites. `system-design` studies one system shape at a time, and
`projects` implements some of those cases in code. Each project README links
back to the case it came from.

## Status

The book is at its first edition, August 2026, in both languages. All nineteen
labs are complete. The paper library holds sixteen papers. Six of the twelve
design cases are written. Three projects run. More of each will be added.
